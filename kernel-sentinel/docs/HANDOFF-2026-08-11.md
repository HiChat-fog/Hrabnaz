## 1. 项目是什么

**内核哨兵 (KernelSentinel / ks)** — 基于 eBPF 的 Linux 服务器端内核级威胁检测系统，国安杯（guoancup）申报书项目。

- **技术栈**：Rust 用户态 + aya-rs + eBPF C
- **三层 eBPF 探针**：
  - modern（5.8+ ringbuf，aya）
  - legacy（老内核，aya）
  - ancient_nobtf（3.10/4.19，C loader 旁路，**不是 aya**）
- **四层检测防线**：内核推理引擎 → 用户态规则引擎 → 跨事件关联 → z-score 基线偏离，外加 SHA-256 哈希链取证
- **交付形态**：单二进制（musl 静态，无运行时依赖），申报书 line75 钦定

**申报书**：`/home/hichat/桌面/esbp_codewell/新建 文本文档.txt`
**代码**：`/home/hichat/桌面/esbp_codewell/kernel-sentinel/`

## 7. 已知坑

1. **必须 sudo** 跑 start（eBPF 要 root），否则 memlock 失败→mock 回退→Permission denied
2. **systemd unit 用 `--rules-dir`**，不是 `--rules`
3. **colored 管道自动关色**：重定向想留色用 `--color always`，脚本用 `--color never`
4. **3.10/4.19 用 C loader**（ancient_nobtf），不是 aya；验证器限制：无浮点/无循环/栈512B/指令100万
5. **musl 构建**：`.cargo/config.toml` 注入 `CC=gcc AR=ar` 编 ring，rust-lld 链接 static-pie；memlock setrlimit 须在预检前
6. **loadgen 压测脚本**：`/tmp/ks-loadgen.sh [workers] [seconds]`，8 worker 高频 fork 短命进程是泄漏/误报的放大器
7. **服务器网络 timeout**：scp 36MB 二进制可能 2 分钟 timeout，重试 + 长 timeout
